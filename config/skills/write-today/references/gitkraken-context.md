# Private GitKraken context

When gathering a work log, read `~/.config/agent-context/write-today/gitkraken-context.md` if it exists.
That private file holds checkout locations, identity hints, the intended Notion destination and its previously observed schema.
Verify those changing facts through the current repository and connected accounts before relying on them.

When the private context is unavailable, use the repositories and destination supplied in the current request, and discover relevant activity through the connected GitHub account.
Resolve the intended Notion workspace and database before reading or writing daily entries; ask Luis when the destination is ambiguous.
If Notion context cannot be established, produce a supported draft and identify the missing context.
Keep personal destination IDs, account details and machine paths in private configuration.
