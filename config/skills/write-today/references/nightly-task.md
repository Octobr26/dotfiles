# Nightly draft configuration

When creating, inspecting or running the nightly draft, read `~/.config/agent-context/write-today/nightly-task.md` if it exists.
It holds the personal schedule, working directory and saved task prompt.
A saved definition does not establish that a schedule is active; verify the scheduler and its latest run separately.

Use the skill's nightly draft mode to gather dated evidence and return a reviewable draft.
Preserve its draft-only boundary and report unavailable sources without waiting for input in an unattended run.
Ask for missing schedule or working-directory choices before creating or changing a scheduled task.
Keep personal scheduling configuration outside public repositories.
