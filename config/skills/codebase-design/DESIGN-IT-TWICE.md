# Compare alternative interfaces

Use only for a material unresolved interface decision.
State the requirement, real callers, constraints, and competing priorities.
Sketch a small number of genuinely different options, with a usage example and the behavior each hides or exposes.
Compare caller complexity, ownership, compatibility, failure handling, verification, and migration cost.
Recommend the simplest option meeting the requirement and state the deciding tradeoff.

The coordinator decides whether separate agents add value under the selected workflow and available authority.
This reference does not require delegation, a fixed number of designs, or a larger agent/model budget.
An unresolved choice belongs to the user only when the governing clarification gate makes it material.
