# Decision record format

Use the existing decision-record location, numbering, and structure first.
Create a record only within authorized documentation work when the decision is consequential to reverse, surprising without context, and based on a real tradeoff.

A short fallback format:

```markdown
# Decision title

Context and requirement: what made a choice necessary.
Decision: what was actually agreed, by whom when relevant.
Reason: the deciding tradeoff and material rejected alternative.
Evidence: sources needed to understand or revisit it.
```

Distinguish proposed from accepted decisions and link any superseded record.
Do not create boilerplate sections or a new decision framework for routine implementation choices.
